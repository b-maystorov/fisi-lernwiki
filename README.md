# FISI Lern-Wiki

Dieses Repository ist meine persönliche Wissenssammlung für die Umschulung zum **Fachinformatiker für Systemintegration (FISI)**.

Hier sammle ich wichtige Themen aus den Lernfeldern, eigene Zusammenfassungen, technische Grundlagen und praktische Beispiele.

Der Fokus liegt darauf, IT-Themen verständlich, sauber und öffentlich dokumentierbar aufzubereiten.

---

## Ziel des Wikis

Das Ziel dieses Repositories ist es, Lerninhalte Schritt für Schritt zu strukturieren und mit eigenen Worten zu erklären.

Dabei geht es nicht darum, Schulunterlagen 1:1 zu kopieren, sondern die wichtigsten Themen allgemein verständlich zusammenzufassen.
