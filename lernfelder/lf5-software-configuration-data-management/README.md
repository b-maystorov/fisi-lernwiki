# LF5: Software zur Verwaltung von Daten anpassen

In diesem Lernfeld geht es darum, Softwarelösungen zu verstehen, anzupassen und zur Verwaltung von Daten einzusetzen.

Dabei stehen grundlegende Themen der Softwareentwicklung im Mittelpunkt: Anforderungen erfassen, einfache Programme planen, Programmierwerkzeuge nutzen, Daten speichern, Datenbanken verstehen, Anwendungen testen, Fehler beheben und Ergebnisse dokumentieren.

Für Fachinformatiker für Systemintegration ist LF5 wichtig, weil auch im Bereich Systemintegration immer wieder Software angepasst, Skripte geschrieben, Daten verarbeitet oder Systeme automatisiert werden müssen.

---

## Ziel von LF5

Das Ziel von LF5 ist, einfache Softwarelösungen zur Datenverwaltung zu verstehen und anzupassen.

Dabei geht es nicht darum, sofort große Anwendungen zu entwickeln. Wichtig ist zuerst, den Ablauf von Softwareentwicklung zu verstehen und einfache Programme sicher zu planen, umzusetzen, zu testen und zu dokumentieren.

Wichtige Themen sind:

- Umfeld der Softwareentwicklung
- Daten und Datenverwaltung
- Projektarbeit in der Softwareentwicklung
- Anforderungen und Planung
- Programmiersprachen
- Entwicklungswerkzeuge
- einfache Python-Anwendungen
- Datenbanken
- SQL-Grundlagen
- Testen und Debugging
- Dokumentation
- Bewertung und Verbesserung von Software

## Warum LF5 wichtig ist

Auch Fachinformatiker für Systemintegration arbeiten nicht nur mit Hardware, Netzwerken und Servern.

In der Praxis gibt es viele Situationen, in denen Softwareverständnis wichtig ist:

- kleine Skripte schreiben
- Daten aus Dateien auslesen
- Logdateien analysieren
- Konfigurationen automatisieren
- einfache Tools erstellen
- Datenbanken prüfen
- SQL-Abfragen ausführen
- Fehler in Anwendungen eingrenzen
- Schnittstellen verstehen
- Software installieren und anpassen
- Dokumentation schreiben
- Anforderungen mit Kunden oder Kollegen klären

Ein FISI muss kein reiner Softwareentwickler sein, sollte aber verstehen, wie Software aufgebaut ist und wie Daten verarbeitet werden.

## Daten als Grundlage

Viele IT-Systeme arbeiten mit Daten.

Beispiele für Daten:

- Benutzerdaten
- Kundendaten
- Produktdaten
- Rechnungsdaten
- Logdateien
- Konfigurationsdaten
- Sensordaten
- Inventardaten
- Supporttickets
- Bestellungen
- Messwerte

Software wird häufig genutzt, um solche Daten zu erfassen, zu speichern, zu verändern, auszuwerten oder auszugeben.

Deshalb gehören Softwareentwicklung und Datenverwaltung eng zusammen.

---

## Softwareentwicklung im Überblick

Softwareentwicklung ist ein geplanter Prozess.

Typische Schritte sind:

1. Problem verstehen
2. Anforderungen erfassen
3. Lösung planen
4. Datenstruktur überlegen
5. Programm schreiben
6. Software testen
7. Fehler beheben
8. Ergebnis dokumentieren
9. Software verbessern
10. Software warten

Dieser Ablauf hilft, Software nicht zufällig zu bauen, sondern nachvollziehbar und wartbar zu entwickeln.

## Wichtige Begriffe

| Begriff       | Bedeutung                                       |
| ------------- | ----------------------------------------------- |
| Anforderung   | beschreibt, was eine Software leisten soll      |
| Algorithmus   | Schrittfolge zur Lösung eines Problems          |
| Variable      | speichert einen Wert im Programm                |
| Datentyp      | beschreibt die Art eines Wertes                 |
| Funktion      | wiederverwendbarer Programmteil                 |
| Datenbank     | strukturierte Speicherung von Daten             |
| SQL           | Sprache zur Arbeit mit relationalen Datenbanken |
| Debugging     | Fehlersuche im Programm                         |
| Test          | Prüfung, ob Software korrekt funktioniert       |
| Dokumentation | beschreibt Aufbau, Nutzung und Entscheidungen   |
| Versionierung | Verwaltung von Änderungen am Code               |

Diese Begriffe sind wichtig, um Softwareentwicklung fachlich zu verstehen.

Für Fachinformatiker für Systemintegration ist LF5 besonders nützlich, weil viele Aufgaben im IT-Betrieb durch Software oder Skripte unterstützt werden.

Beispiele aus der Praxis:

- Benutzerlisten auswerten
- Serverlogs analysieren
- Backups prüfen
- Konfigurationsdateien bearbeiten
- einfache Automatisierungen schreiben
- Daten aus CSV-Dateien verarbeiten
- SQL-Datenbanken prüfen
- Fehler in Anwendungen eingrenzen
- Schnittstellen verstehen
- kleine interne Tools bauen
- technische Dokumentation schreiben

Ein guter FISI versteht nicht nur fertige Software, sondern auch die Grundidee dahinter: Eingabe, Verarbeitung, Speicherung und Ausgabe von Daten.
