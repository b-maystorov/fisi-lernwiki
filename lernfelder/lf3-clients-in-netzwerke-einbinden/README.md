# LF3: Clients in Rechnernetzwerke einbinden

In diesem Lernfeld geht es darum, Clients in bestehende oder neue Netzwerke einzubinden.

Der Fokus liegt auf Netzwerkgrundlagen, Datenübertragung, IP-Adressierung, Ethernet, TCP/IP, Netzwerkkomponenten, Clientintegration, Netzwerktests, Sicherheit und Verfügbarkeit.

Für Fachinformatiker für Systemintegration ist LF3 besonders wichtig, weil fast jede IT-Umgebung auf funktionierenden Netzwerken basiert.

---

## Ziel von LF3

In LF3 werden die Grundlagen vermittelt, die man braucht, um Computer, Laptops und andere Endgeräte sinnvoll in Netzwerke einzubinden.

Dazu gehört nicht nur das Anschließen eines Netzwerkkabels. Man muss verstehen, wie Netzwerke aufgebaut sind, wie Geräte miteinander kommunizieren, welche Dienste benötigt werden und wie man Fehler systematisch analysiert.

Wichtige Themen sind:

- Aufbau von Rechnernetzen
- Clients, Server und Netzwerkgeräte
- Ethernet und TCP/IP
- IP-Adressen, Subnetze, DNS und DHCP
- Switches, Router und Access Points
- LAN, WLAN und WAN
- strukturierte Verkabelung
- Netzwerkdiagnose
- Netzwerksicherheit
- Backup, RAID und Verfügbarkeit
- Stromversorgung und Green IT

## Warum LF3 wichtig ist

Netzwerke sind die Grundlage moderner IT-Systeme.

Ohne Netzwerk können viele Dienste nicht sinnvoll genutzt werden:

- Internet
- Dateiablagen
- Drucker
- E-Mail
- Cloud-Dienste
- Serverdienste
- Benutzeranmeldung
- Updates
- Monitoring
- Fernwartung
- Backup-Systeme

Ein einzelner Computer kann lokal funktionieren, aber in Unternehmen ist er meistens Teil einer größeren IT-Umgebung.

Deshalb muss ein FISI verstehen, wie Clients mit Netzwerken verbunden werden und wie man Netzwerkprobleme erkennt.

---

## Typische Aufgaben in LF3

Typische Aufgaben in diesem Lernfeld sind:

- Netzwerkaufbau erklären
- Clients ins LAN oder WLAN einbinden
- IP-Konfiguration prüfen
- DNS- und DHCP-Funktion verstehen
- Netzwerkverbindungen testen
- Switches und Router einordnen
- Verkabelung und Standards verstehen
- einfache Fehleranalyse durchführen
- Sicherheitsaspekte im Netzwerk beachten
- Netzwerkkonfiguration dokumentieren

## Wichtige Grundbegriffe

| Begriff     | Bedeutung                                   |
| ----------- | ------------------------------------------- |
| Client      | Endgerät, das Dienste nutzt                 |
| Server      | System, das Dienste bereitstellt            |
| LAN         | lokales Netzwerk                            |
| WLAN        | drahtloses Netzwerk                         |
| WAN         | großes Netzwerk über Standorte hinweg       |
| IP-Adresse  | logische Adresse eines Geräts im Netzwerk   |
| MAC-Adresse | Hardwareadresse einer Netzwerkschnittstelle |
| Switch      | verbindet Geräte im lokalen Netzwerk        |
| Router      | verbindet verschiedene Netzwerke            |
| DNS         | übersetzt Namen in IP-Adressen              |
| DHCP        | vergibt Netzwerkeinstellungen automatisch   |
| Gateway     | Übergang in andere Netzwerke                |
| Subnetz     | Teilbereich eines IP-Netzwerks              |

## FISI-Bezug

Für Fachinformatiker für Systemintegration ist LF3 eines der wichtigsten technischen Lernfelder.

Viele praktische Aufgaben im Beruf hängen direkt mit Netzwerken zusammen:

- Arbeitsplatzrechner einrichten
- Netzwerkprobleme analysieren
- Serverdienste erreichbar machen
- WLAN-Zugänge konfigurieren
- Drucker ins Netzwerk einbinden
- IP-Adressen prüfen
- Benutzerzugriff auf Netzlaufwerke ermöglichen
- Netzwerkdokumentation erstellen
- Sicherheitsmaßnahmen im Netzwerk beachten

Ein guter FISI muss nicht nur wissen, dass ein Gerät “Internet hat”, sondern verstehen, warum die Verbindung funktioniert oder warum sie nicht funktioniert.

## Kurze Zusammenfassung

LF3 behandelt die Einbindung von Clients in Rechnernetzwerke.

Dazu gehören technische Grundlagen wie Ethernet, TCP/IP, IP-Adressen, DNS, DHCP, Switches, Router, WLAN, Verkabelung, Netzwerkdiagnose und Netzwerksicherheit.

Dieses Lernfeld bildet eine wichtige Grundlage für Systemadministration, Netzwerkadministration und viele praktische Aufgaben in der IT.
