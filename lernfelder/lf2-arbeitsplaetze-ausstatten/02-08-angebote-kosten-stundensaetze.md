# 2.8 Angebote, Kosten und Stundensätze kalkulieren

In diesem Kapitel geht es darum, IT-Leistungen wirtschaftlich zu planen und zu kalkulieren.

Ein IT-Arbeitsplatz besteht nicht nur aus Hardware und Software. Auch Beratung, Installation, Konfiguration, Dokumentation, Support, Wartung und Projektaufwand verursachen Kosten.

Für Fachinformatiker für Systemintegration ist dieses Thema wichtig, weil technische Lösungen nicht nur funktionieren, sondern auch wirtschaftlich sinnvoll sein müssen.

---

## Kurz erklärt

Eine Kalkulation zeigt, welche Kosten entstehen und zu welchem Preis eine Leistung angeboten werden kann.

Im IT-Bereich müssen dabei mehrere Kostenarten berücksichtigt werden:

- Hardwarekosten
- Software- und Lizenzkosten
- Arbeitszeit
- Fahrtkosten
- Supportkosten
- Wartungskosten
- Gemeinkosten
- Risikoaufschläge
- Gewinnzuschlag

Ein Angebot sollte für den Kunden verständlich sein und gleichzeitig für das Unternehmen wirtschaftlich bleiben.

---

## Warum Kalkulation in der IT wichtig ist

IT-Projekte können schnell teurer werden, wenn Aufwände falsch eingeschätzt werden.

Typische Gründe sind:

- Installationen dauern länger als geplant
- Kompatibilitätsprobleme treten auf
- zusätzliche Lizenzen werden benötigt
- Benutzer brauchen mehr Support
- Dokumentation wird vergessen
- Sicherheitsanforderungen werden unterschätzt
- Änderungen kommen während der Umsetzung dazu

Eine saubere Kalkulation hilft, Kosten realistisch zu planen und spätere Missverständnisse zu vermeiden.

---

## Angebot

Ein Angebot ist eine verbindliche oder unverbindliche Erklärung, zu welchen Bedingungen ein Unternehmen eine Leistung erbringen möchte.

Ein IT-Angebot beschreibt normalerweise:

- welche Leistung erbracht wird
- welche Produkte geliefert werden
- welche Kosten entstehen
- welche Bedingungen gelten
- wie lange das Angebot gültig ist
- welche Leistungen enthalten oder ausgeschlossen sind

Ein gutes Angebot ist klar, nachvollziehbar und vollständig.

---

## Bestandteile eines IT-Angebots

Typische Bestandteile eines Angebots:

| Bestandteil           | Bedeutung                            |
| --------------------- | ------------------------------------ |
| Kundendaten           | Name, Adresse, Ansprechpartner       |
| Angebotsnummer        | eindeutige Zuordnung                 |
| Datum                 | Erstellungsdatum                     |
| Leistungsbeschreibung | was geliefert oder umgesetzt wird    |
| Einzelpositionen      | Hardware, Software, Dienstleistungen |
| Mengen                | Anzahl der Geräte oder Stunden       |
| Einzelpreise          | Preis pro Stück oder pro Stunde      |
| Gesamtpreise          | Summe je Position                    |
| Umsatzsteuer          | gesetzliche Mehrwertsteuer           |
| Gesamtbetrag          | Endpreis                             |
| Lieferzeit            | wann geliefert werden kann           |
| Zahlungsbedingungen   | wann und wie bezahlt wird            |
| Gültigkeit            | wie lange das Angebot gilt           |
| Abgrenzung            | was nicht enthalten ist              |

Besonders wichtig ist eine klare Leistungsbeschreibung. Wenn unklar ist, was enthalten ist, entstehen später oft Diskussionen.

---

## Leistungsbeschreibung

Die Leistungsbeschreibung erklärt, was genau angeboten wird.

Sie sollte nicht zu allgemein formuliert sein.

Ungenau wäre:

> Einrichtung von zehn Arbeitsplätzen.

Besser wäre:

> Lieferung und Einrichtung von zehn Business-Laptops inklusive Betriebssystem, Standardsoftware, Benutzerprofil, Netzwerkzugang, Druckerinstallation, Sicherheitssoftware, Updates, Funktionstest und Übergabedokumentation.

Eine gute Leistungsbeschreibung schützt beide Seiten.  
Der Kunde versteht, was er bekommt. Der Dienstleister kann nachweisen, was vereinbart wurde.

---

## Umsatz, Kosten und Gewinn

Im wirtschaftlichen Teil unterscheidet man zwischen Umsatz, Kosten und Gewinn.

| Begriff | Bedeutung                                                    |
| ------- | ------------------------------------------------------------ |
| Umsatz  | Geld, das durch Verkauf oder Dienstleistung eingenommen wird |
| Kosten  | Aufwand, der für Leistungserbringung entsteht                |
| Gewinn  | Betrag, der nach Abzug der Kosten übrig bleibt               |
| Verlust | entsteht, wenn Kosten höher sind als Umsatz                  |

Grundformel:

```text
Gewinn = Umsatz - Kosten
```
