# 2.2 Leistungsportfolio im IT-Bereich

In diesem Kapitel geht es darum, welche Leistungen ein IT-Unternehmen oder eine interne IT-Abteilung anbieten kann.

Ein Leistungsportfolio beschreibt, welche Produkte, Dienstleistungen und Lösungen für Kunden oder Mitarbeiter bereitgestellt werden.

Für FISI ist das wichtig, weil man verstehen muss, welche technischen Leistungen zu einem vollständigen IT-Arbeitsplatz gehören.

---

## Ziel dieses Kapitels

Nach diesem Kapitel sollte ich erklären können:

- was ein Leistungsportfolio ist
- welche IT-Leistungen zu einem Arbeitsplatz gehören können
- welche Unterschiede es zwischen Produkten und Dienstleistungen gibt
- welche Arbeitsplatzarten es geben kann
- warum Beratung, Installation, Support und Dokumentation dazugehören
- wie ein IT-Dienstleister Kundenanforderungen in passende Lösungen umsetzt

---

## Was ist ein Leistungsportfolio?

Ein Leistungsportfolio ist eine Übersicht über alle Leistungen, die ein Unternehmen anbietet.

Im IT-Bereich können das zum Beispiel sein:

- Hardware verkaufen oder bereitstellen
- Software installieren
- Arbeitsplätze einrichten
- Netzwerke planen
- Server betreiben
- Benutzerkonten anlegen
- IT-Sicherheit umsetzen
- Support leisten
- Systeme warten
- Dokumentationen erstellen
- Kunden beraten

Ein Leistungsportfolio zeigt also nicht nur, **was verkauft wird**, sondern auch, **welche IT-Dienstleistungen angeboten werden**.

---

## Einfaches Beispiel

Ein Kunde sagt:

> Wir brauchen fünf neue Arbeitsplätze für unser Büro.

Dann reicht es nicht, einfach fünf Laptops zu kaufen.

Zu einer vollständigen Lösung können gehören:

- passende Laptops auswählen
- Monitore, Tastaturen und Mäuse beschaffen
- Betriebssystem installieren
- Benutzerkonten einrichten
- Office-Programme installieren
- Drucker einrichten
- Netzwerkzugang konfigurieren
- Sicherheitssoftware aktivieren
- Datenzugriff einrichten
- Übergabe dokumentieren
- Benutzer kurz einweisen

Das alles zusammen gehört zum Leistungsportfolio.

---

## Produkte und Dienstleistungen

Im IT-Bereich unterscheidet man oft zwischen Produkten und Dienstleistungen.

### Produkte

Produkte sind Dinge, die gekauft oder bereitgestellt werden.

Beispiele:

- Laptop
- Desktop-PC
- Monitor
- Drucker
- Scanner
- Switch
- Router
- Server
- Softwarelizenz
- Dockingstation
- Netzwerkkabel

### Dienstleistungen

Dienstleistungen sind Arbeiten oder Services, die erbracht werden.

Beispiele:

- Beratung
- Installation
- Konfiguration
- Wartung
- Fehleranalyse
- Support
- Schulung
- Dokumentation
- Datensicherung
- Sicherheitsprüfung

### Einfacher Vergleich

Ein Laptop ist ein Produkt.  
Die Einrichtung des Laptops ist eine Dienstleistung.

Eine Softwarelizenz ist ein Produkt.  
Die Installation und Konfiguration der Software ist eine Dienstleistung.

---

## IT-Arbeitsplätze als Teil des Leistungsportfolios

Ein wichtiger Teil des Leistungsportfolios ist die Ausstattung von Arbeitsplätzen.

Arbeitsplätze können sehr unterschiedlich sein.

| Arbeitsplatzart          | Typische Nutzung                                |
| ------------------------ | ----------------------------------------------- |
| Büroarbeitsplatz         | E-Mail, Office, Browser, Drucken                |
| Homeoffice-Arbeitsplatz  | mobiles Arbeiten, VPN, Cloud-Zugriff            |
| Entwicklungsarbeitsplatz | Programmierung, Git, IDE, Container, VMs        |
| Grafikarbeitsplatz       | Bildbearbeitung, Design, starke GPU             |
| CAD-Arbeitsplatz         | technische Zeichnungen, hohe Leistung           |
| Schulungsarbeitsplatz    | einfache Einrichtung, schnell wiederherstellbar |
| Thin-Client-Arbeitsplatz | zentrale Anwendungen auf Servern                |

Nicht jeder Arbeitsplatz braucht die gleiche Hardware und Software.

Deshalb muss man vorher verstehen, was der Benutzer wirklich braucht.

---

## Standardarbeitsplatz

Ein Standardarbeitsplatz ist ein häufig genutzter Arbeitsplatztyp in Unternehmen.

Typische Ausstattung:

- Business-Laptop oder Desktop-PC
- Monitor
- Tastatur und Maus
- Betriebssystem
- Office-Programme
- Browser
- E-Mail-Zugang
- Druckerzugriff
- Netzwerkzugang
- Sicherheitssoftware
- Benutzerkonto

Der Vorteil eines Standardarbeitsplatzes ist, dass er einfacher zu verwalten ist.

Wenn viele Mitarbeiter ähnliche Geräte und Programme nutzen, wird Support und Wartung leichter.

---

## Individueller Arbeitsplatz

Manche Benutzer brauchen besondere Ausstattung.

Beispiele:

Ein Entwickler braucht vielleicht:

- mehr RAM
- schnelle CPU
- große SSD
- Linux oder Windows mit WSL
- Git
- Docker
- Entwicklungsumgebung
- Zugriff auf Repositories

Ein Grafikdesigner braucht vielleicht:

- starke Grafikkarte
- farbgenauer Monitor
- viel Speicherplatz
- spezielle Grafiksoftware

Ein CAD-Nutzer braucht vielleicht:

- Workstation
- starke CPU
- professionelle Grafikkarte
- viel RAM
- zertifizierte Software

Hier sieht man: Gute IT-Ausstattung hängt immer vom Einsatzzweck ab.

---

## Beratung als IT-Leistung

Beratung ist ein wichtiger Teil des Leistungsportfolios.

Der IT-Dienstleister muss herausfinden:

- Was möchte der Kunde erreichen?
- Wie viele Arbeitsplätze werden benötigt?
- Welche Programme werden genutzt?
- Gibt es besondere Leistungsanforderungen?
- Gibt es Sicherheitsanforderungen?
- Gibt es ein Budget?
- Gibt es vorhandene Systeme?
- Wie soll später Support geleistet werden?

Ohne gute Beratung kann schnell eine falsche Lösung entstehen.

Beispiel:

Ein Kunde kauft günstige Laptops mit wenig RAM. Später merkt man, dass die Mitarbeiter mehrere große Programme gleichzeitig nutzen müssen. Dann sind die Geräte zu langsam und der Kunde ist unzufrieden.

---

## Beschaffung als IT-Leistung

Beschaffung bedeutet, passende IT-Produkte auszuwählen und zu kaufen.

Dabei achtet man auf:

- Preis
- Leistung
- Qualität
- Garantie
- Lieferzeit
- Kompatibilität
- Energieverbrauch
- Support durch Hersteller
- Verfügbarkeit von Ersatzteilen
- Sicherheitsfunktionen

Beschaffung bedeutet also nicht einfach “das billigste Gerät kaufen”.

Es geht darum, die passende Lösung für den Einsatzbereich zu finden.

---

## Installation und Konfiguration

Nach der Beschaffung müssen die Systeme eingerichtet werden.

Typische Aufgaben:

- Betriebssystem installieren
- Updates installieren
- Treiber einrichten
- Programme installieren
- Benutzerkonten einrichten
- Netzwerk konfigurieren
- Drucker hinzufügen
- Sicherheitssoftware aktivieren
- Grundeinstellungen setzen

Konfiguration bedeutet, ein System so einzustellen, dass es zum Kunden und zur Aufgabe passt.

---

## Support und Wartung

Nach der Übergabe ist die Arbeit nicht automatisch vorbei.

IT-Systeme müssen betreut werden.

Support bedeutet Hilfe bei Problemen.

Beispiele:

- Benutzer kann sich nicht anmelden
- Internet funktioniert nicht
- Drucker druckt nicht
- Programm startet nicht
- Passwort muss zurückgesetzt werden
- Datei kann nicht geöffnet werden

Wartung bedeutet, Systeme regelmäßig aktuell und funktionsfähig zu halten.

Beispiele:

- Updates installieren
- Sicherheitslücken schließen
- Backups prüfen
- Speicherplatz kontrollieren
- Geräte inventarisieren
- alte Hardware ersetzen

---

## Dokumentation

Dokumentation ist ein sehr wichtiger Teil der IT-Arbeit.

Dokumentiert werden zum Beispiel:

- welche Geräte verwendet werden
- welche Software installiert ist
- welche Benutzer Zugriff haben
- welche IP-Adressen genutzt werden
- welche Passwörter oder Zugangsdaten sicher verwaltet werden
- welche Änderungen gemacht wurden
- welche Fehler aufgetreten sind
- wie ein System wiederhergestellt werden kann

Gute Dokumentation hilft später bei Support, Wartung und Fehlersuche.

Ohne Dokumentation muss man vieles neu herausfinden.

---

## IT-Sicherheit im Leistungsportfolio

IT-Sicherheit gehört zu fast jeder IT-Leistung dazu.

Beispiele:

- sichere Passwörter
- Updates
- Virenschutz
- Firewall
- Benutzerrechte
- Backup
- Verschlüsselung
- Mehrfaktor-Authentifizierung
- Schutz vor Phishing
- sichere Netzwerkkonfiguration

Ein neuer Arbeitsplatz sollte nicht nur funktionieren, sondern auch sicher sein.

Für Unternehmen ist das besonders wichtig, weil Kundendaten, interne Dokumente und Zugangsdaten geschützt werden müssen.

---

## Service Level und Reaktionszeiten

Manche IT-Leistungen werden mit festen Service-Regeln angeboten.

Das nennt man oft SLA.

SLA bedeutet **Service Level Agreement**.

Darin kann stehen:

- wann Support erreichbar ist
- wie schnell auf Probleme reagiert wird
- welche Systeme betreut werden
- welche Leistungen enthalten sind
- welche Zeiten für Wartung geplant sind

Beispiel:

Ein Unternehmen bezahlt für einen Supportvertrag. Dann wird vereinbart, dass kritische Störungen innerhalb von vier Stunden bearbeitet werden.

---

## Internes IT-Team und externer IT-Dienstleister

IT-Leistungen können intern oder extern erbracht werden.

### Internes IT-Team

Ein internes IT-Team gehört direkt zum Unternehmen.

Vorteile:

- kennt die eigene Umgebung gut
- ist oft schneller vor Ort
- kennt die Benutzer und Prozesse

Nachteile:

- kostet dauerhaft Personal
- braucht viele verschiedene Kenntnisse
- kann bei großen Projekten überlastet sein

### Externer IT-Dienstleister

Ein externer IT-Dienstleister wird von einem Kunden beauftragt.

Vorteile:

- Spezialwissen
- flexible Unterstützung
- Erfahrung aus vielen Projekten

Nachteile:

- kennt die Umgebung nicht immer sofort
- Abhängigkeit vom Dienstleister
- zusätzliche Kosten

---

## Praxisbeispiel: Neues Büro ausstatten

Ein kleines Unternehmen eröffnet ein neues Büro mit zehn Arbeitsplätzen.

Mögliche Leistungen aus dem IT-Portfolio:

1. Beratungsgespräch führen
2. Anforderungen aufnehmen
3. Hardware auswählen
4. Angebot erstellen
5. Geräte bestellen
6. Betriebssystem und Programme installieren
7. Benutzerkonten einrichten
8. Netzwerk und WLAN einrichten
9. Drucker einbinden
10. Sicherheitssoftware aktivieren
11. Backup-Konzept prüfen
12. Arbeitsplatz testen
13. Übergabe dokumentieren
14. Benutzer einweisen
15. Support anbieten

Dieses Beispiel zeigt, dass ein IT-Arbeitsplatz aus vielen einzelnen Leistungen besteht.

---

## FISI-Bezug

Für Fachinformatiker für Systemintegration ist ein Leistungsportfolio wichtig, weil man technische Lösungen nicht isoliert betrachten darf.

Man muss immer fragen:

- Was braucht der Kunde wirklich?
- Welche Lösung passt technisch?
- Welche Lösung ist wirtschaftlich sinnvoll?
- Welche Sicherheitsanforderungen gibt es?
- Wie wird die Lösung später betreut?
- Wie wird alles dokumentiert?

Ein guter FISI denkt nicht nur an Hardware, sondern an die komplette IT-Lösung.

---

## Typische Fehler

Typische Fehler bei IT-Leistungen:

| Fehler                           | Problem                                   |
| -------------------------------- | ----------------------------------------- |
| Nur den Preis betrachten         | Gerät ist später vielleicht zu schwach    |
| Anforderungen nicht genau klären | Kunde bekommt falsche Lösung              |
| Dokumentation vergessen          | Support wird später schwieriger           |
| Sicherheit nicht beachten        | Risiko für Daten und Netzwerk             |
| Keine Tests durchführen          | Fehler fallen erst beim Benutzer auf      |
| Keine Übergabe machen            | Benutzer weiß nicht, wie er arbeiten soll |

---

## Kurze Zusammenfassung

Ein Leistungsportfolio beschreibt, welche Produkte und Dienstleistungen ein IT-Unternehmen oder eine IT-Abteilung anbietet.

Im Bereich IT-Arbeitsplätze gehören dazu nicht nur Geräte, sondern auch Beratung, Beschaffung, Installation, Konfiguration, Support, Wartung, Sicherheit und Dokumentation.

Für FISI ist wichtig, komplette Lösungen zu verstehen und nicht nur einzelne Hardwareteile zu betrachten.
