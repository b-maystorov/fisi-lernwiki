# 2.1 Einführung in die IT für Arbeitsplätze

In diesem Kapitel geht es um die Grundlagen von IT-Arbeitsplätzen.

Ein IT-Arbeitsplatz ist nicht nur ein einzelner Computer. Dazu gehören mehrere Teile, die zusammen funktionieren müssen: Hardware, Software, Netzwerk, Benutzerkonto, Sicherheit, Peripheriegeräte und die passende Einrichtung für die Aufgabe des Benutzers.

Für Fachinformatiker für Systemintegration ist dieses Thema wichtig, weil man Arbeitsplätze planen, einrichten, prüfen, warten und an Kunden oder Mitarbeiter übergeben muss.

---

## Ziel dieses Kapitels

Nach diesem Kapitel sollte ich erklären können:

- was ein IT-Arbeitsplatz ist
- welche Grundfunktionen ein Computer hat
- was Hardware und Software unterscheidet
- welche Geräte zu einem Arbeitsplatz gehören können
- warum Netzwerk, Benutzerkonten und Sicherheit dazugehören
- wie sich Computertechnik entwickelt hat
- welche aktuellen Trends Arbeitsplätze verändern
- warum unterschiedliche Aufgaben unterschiedliche IT-Ausstattung brauchen

---

## Was ist ein IT-Arbeitsplatz?

Ein IT-Arbeitsplatz ist die technische Umgebung, mit der eine Person ihre Arbeit erledigt.

Dazu können gehören:

- Computer oder Laptop
- Monitor
- Tastatur und Maus
- Betriebssystem
- Programme
- Netzwerkzugang
- Internetzugang
- Benutzerkonto
- Drucker oder Scanner
- Telefonie oder Headset
- Speicherorte und Freigaben
- Sicherheitssoftware
- Backup-Lösung
- Zugriffsrechte

Ein IT-Arbeitsplatz muss zur Aufgabe passen.

Ein einfacher Büroarbeitsplatz braucht oft weniger Leistung als ein Arbeitsplatz für Softwareentwicklung, CAD, Grafikbearbeitung, Videoschnitt oder Virtualisierung.

---

## Warum ist das für FISI wichtig?

FISI bedeutet nicht nur “Computer anschließen”.

Man muss verstehen:

- welche Anforderungen der Benutzer hat
- welche Hardware dazu passt
- welche Software benötigt wird
- wie der Arbeitsplatz ins Netzwerk kommt
- welche Zugriffsrechte gebraucht werden
- welche Sicherheitsregeln gelten
- wie man Fehler später analysiert
- wie man die Einrichtung dokumentiert

Ein schlecht geplanter Arbeitsplatz kann später viele Probleme verursachen.

Beispiele:

- Der PC ist zu langsam für die Aufgabe.
- Es fehlt RAM für mehrere Programme.
- Die SSD ist zu klein.
- Der Benutzer hat keinen Zugriff auf wichtige Freigaben.
- Drucker oder Scanner funktionieren nicht.
- Das Gerät ist nicht ausreichend geschützt.
- Es gibt keine saubere Dokumentation.

## 2.1.1 Grundfunktionen eines Computers

Ein Computer verarbeitet Informationen.

Vereinfacht kann man die Arbeit eines Computers in vier Grundfunktionen einteilen:

| Grundfunktion | Bedeutung                                          | Beispiel                          |
| ------------- | -------------------------------------------------- | --------------------------------- |
| Eingabe       | Daten werden in das System eingegeben              | Tastatur, Maus, Scanner, Mikrofon |
| Verarbeitung  | Daten werden berechnet oder bearbeitet             | CPU verarbeitet Befehle           |
| Speicherung   | Daten werden kurzzeitig oder dauerhaft gespeichert | RAM, SSD, HDD                     |
| Ausgabe       | Ergebnisse werden angezeigt oder ausgegeben        | Monitor, Drucker, Lautsprecher    |

---

## Einfache Erklärung der Grundfunktionen

Ein Computer bekommt Daten, verarbeitet sie und gibt ein Ergebnis aus.

Beispiel: Ein Textdokument schreiben

1. Ich tippe Text mit der Tastatur ein.
2. Die Eingabe wird vom Computer verarbeitet.
3. Das Dokument liegt während der Bearbeitung im Arbeitsspeicher.
4. Beim Speichern wird es dauerhaft auf der SSD abgelegt.
5. Der Text wird auf dem Monitor angezeigt.

Das gleiche Grundprinzip gilt auch bei komplexeren Aufgaben.

Beispiel: Webseite öffnen

1. Ich gebe eine Adresse im Browser ein.
2. Der Computer verarbeitet die Eingabe.
3. Über das Netzwerk werden Daten vom Webserver geladen.
4. Der Browser zeigt die Webseite auf dem Monitor an.
5. Teile der Daten können im Cache gespeichert werden.

---

## Eingabe

Eingabegeräte bringen Informationen in den Computer.

Beispiele:

- Tastatur
- Maus
- Touchpad
- Touchscreen
- Scanner
- Mikrofon
- Webcam
- Kartenleser

Ohne Eingabe kann der Benutzer dem Computer keine Befehle geben.

---

## Verarbeitung

Die Verarbeitung übernimmt hauptsächlich die CPU.

CPU bedeutet **Central Processing Unit**. Auf Deutsch sagt man meistens **Prozessor**.

Die CPU verarbeitet Befehle und Berechnungen. Sie ist ein zentrales Bauteil im Computer.

Beispiele für Verarbeitung:

- Programme starten
- Berechnungen durchführen
- Daten sortieren
- Webseiten darstellen
- Dateien komprimieren
- Spiel- oder Grafikberechnungen unterstützen

Die CPU arbeitet dabei mit anderen Komponenten zusammen, zum Beispiel RAM, SSD und Mainboard.

---

## Speicherung

Daten können kurzzeitig oder dauerhaft gespeichert werden.

### RAM

RAM ist der Arbeitsspeicher.

Dort liegen Daten, die der Computer gerade schnell braucht.

Beispiel:

Wenn ein Browser, ein Textprogramm und ein Chatprogramm gleichzeitig offen sind, werden viele Daten im RAM gehalten.

Mehr RAM hilft, wenn viele Programme gleichzeitig genutzt werden oder wenn Programme viel Speicher brauchen.

RAM ist aber flüchtig. Das bedeutet: Wenn der Computer ausgeschaltet wird, sind die Daten im RAM weg.

### SSD / HDD

SSD und HDD speichern Daten dauerhaft.

Dort liegen zum Beispiel:

- Betriebssystem
- Programme
- Dokumente
- Bilder
- Videos
- Projektdaten

Eine SSD ist deutlich schneller als eine alte HDD. Dadurch startet das System schneller und Programme öffnen sich schneller.

---

## Ausgabe

Ausgabegeräte zeigen dem Benutzer Ergebnisse an oder geben sie aus.

Beispiele:

- Monitor
- Drucker
- Lautsprecher
- Beamer
- Kopfhörer

Ohne Ausgabe könnte der Benutzer nicht sehen oder hören, was der Computer macht.

---

## Hardware und Software

Ein IT-Arbeitsplatz braucht Hardware und Software.

### Hardware

Hardware sind alle physischen Teile eines IT-Systems.

Man kann Hardware anfassen.

Beispiele:

- PC
- Laptop
- Monitor
- Tastatur
- Maus
- Drucker
- Scanner
- Mainboard
- CPU
- RAM
- SSD
- Netzteil
- Netzwerkkabel
- Dockingstation

### Software

Software sind Programme und Daten, die auf der Hardware laufen.

Beispiele:

- Betriebssystem
- Browser
- Office-Programme
- E-Mail-Programm
- Treiber
- Sicherheitssoftware
- Fachanwendungen
- Datenbankprogramme
- Verwaltungssoftware

### Einfacher Vergleich

Hardware ist das Gerät.  
Software sagt dem Gerät, was es tun soll.

Ohne Hardware kann Software nicht laufen.  
Ohne Software kann Hardware nicht sinnvoll genutzt werden.

---

## Betriebssystem

Das Betriebssystem ist die wichtigste Software auf einem Computer.

Es verwaltet die Hardware und stellt die Grundlage für Programme bereit.

Beispiele:

- Windows
- Linux
- macOS

Aufgaben eines Betriebssystems:

- Benutzer anmelden
- Programme starten
- Dateien verwalten
- Hardware ansprechen
- Netzwerkverbindungen verwalten
- Rechte und Sicherheit steuern
- Updates installieren

Für FISI ist es wichtig, Betriebssysteme nicht nur zu benutzen, sondern auch grundlegend zu verstehen.

---

## Treiber

Ein Treiber ist Software, die dem Betriebssystem hilft, Hardware richtig zu nutzen.

Beispiele:

- Druckertreiber
- Grafikkartentreiber
- Netzwerkkartentreiber
- Audio-Treiber
- Scanner-Treiber

Wenn ein Treiber fehlt oder falsch ist, funktioniert ein Gerät oft nicht richtig.

Beispiel:

Ein Drucker ist angeschlossen, aber Windows oder Linux kann ihn nicht korrekt verwenden, weil der passende Treiber fehlt.

---

## Netzwerk am Arbeitsplatz

Ein moderner IT-Arbeitsplatz ist meistens mit einem Netzwerk verbunden.

Über das Netzwerk bekommt der Benutzer Zugriff auf:

- Internet
- Dateiablagen
- Drucker
- Server
- E-Mail
- Unternehmensanwendungen
- Cloud-Dienste
- Updates

Ohne Netzwerk funktionieren viele Arbeitsplätze nur eingeschränkt.

Wichtige Begriffe:

| Begriff    | Bedeutung                                      |
| ---------- | ---------------------------------------------- |
| IP-Adresse | Adresse eines Geräts im Netzwerk               |
| DNS        | übersetzt Namen in IP-Adressen                 |
| DHCP       | vergibt IP-Adressen automatisch                |
| Gateway    | Weg aus dem lokalen Netzwerk, meist der Router |
| WLAN       | drahtloses Netzwerk                            |
| LAN        | kabelgebundenes Netzwerk                       |

Diese Themen werden später in LF3 deutlich wichtiger.

---

## Benutzerkonto und Rechte

Ein Arbeitsplatz braucht meistens ein Benutzerkonto.

Über das Benutzerkonto wird geregelt:

- wer sich anmelden darf
- welche Programme genutzt werden dürfen
- auf welche Dateien zugegriffen werden darf
- welche Netzwerkfreigaben sichtbar sind
- ob der Benutzer Adminrechte hat oder nicht

In Unternehmen ist es wichtig, dass Benutzer nur die Rechte bekommen, die sie wirklich brauchen.

Das nennt man oft das Prinzip der minimalen Rechte.

Beispiel:

Ein normaler Benutzer sollte nicht einfach Systemdateien löschen oder Sicherheitssoftware deaktivieren können.

---

## IT-Sicherheit am Arbeitsplatz

IT-Sicherheit gehört zu jedem Arbeitsplatz.

Wichtige Punkte sind:

- sichere Passwörter
- Bildschirmsperre
- Updates
- Virenschutz oder Endpoint-Security
- Firewall
- keine unbekannten USB-Sticks nutzen
- keine privaten Passwörter im Browser speichern
- keine verdächtigen Links öffnen
- Datenschutz beachten

Ein Arbeitsplatz ist oft ein Eingangstor in das Unternehmensnetzwerk. Deshalb muss er geschützt werden.

---

## Ergonomie und Arbeitsplatzgestaltung

Ein IT-Arbeitsplatz soll nicht nur technisch funktionieren. Er soll auch gesund und sinnvoll nutzbar sein.

Wichtige Punkte:

- Monitorhöhe
- Sitzposition
- Tastatur und Maus
- Beleuchtung
- Kabelmanagement
- Lärm
- Pausen
- Barrierefreiheit

Ein schlecht eingerichteter Arbeitsplatz kann langfristig gesundheitliche Probleme verursachen.

Beispiele:

- Rückenschmerzen
- Nackenschmerzen
- Augenbelastung
- Konzentrationsprobleme

---

## 2.1.2 Entwicklungsschritte in der Computertechnik

Computertechnik hat sich stark verändert.

Früher waren Computer sehr groß, teuer und schwer zu bedienen. Heute sind sie kleiner, schneller, mobiler und stärker vernetzt.

Wichtige Entwicklungsschritte:

| Entwicklung             | Bedeutung                                             |
| ----------------------- | ----------------------------------------------------- |
| Großrechner             | große zentrale Computer für Unternehmen und Forschung |
| Personal Computer       | Computer für einzelne Benutzer                        |
| Client-Server-Modell    | Clients greifen auf zentrale Serverdienste zu         |
| Internet                | weltweite Vernetzung von Computern                    |
| Laptops                 | mobile Arbeitsplätze                                  |
| Smartphones und Tablets | mobile IT im Alltag                                   |
| Cloud-Dienste           | Anwendungen und Daten laufen in Rechenzentren         |
| Virtualisierung         | mehrere virtuelle Systeme auf einer Hardware          |
| KI und Automatisierung  | Systeme unterstützen oder automatisieren Aufgaben     |

---

## Vom Einzel-PC zum vernetzten Arbeitsplatz

Früher wurde viel direkt auf einem einzelnen PC gemacht.

Heute sind Arbeitsplätze oft Teil einer größeren IT-Umgebung.

Beispiele:

- Benutzer melden sich an einer Domäne an.
- Dateien liegen auf Servern oder in der Cloud.
- Software wird zentral verteilt.
- Updates werden zentral verwaltet.
- Sicherheitsrichtlinien werden zentral gesetzt.
- Geräte werden inventarisiert und überwacht.

Das macht IT-Arbeitsplätze flexibler, aber auch komplexer.

Moderne IT-Arbeitsplätze verändern sich ständig.

Wichtige Trends:

- mobiles Arbeiten

- stärkere IT-Sicherheit

## Mobiles Arbeiten und Homeoffice

Viele Arbeitsplätze sind heute nicht mehr nur im Büro.

Mitarbeiter arbeiten zum Beispiel:

- im Büro
- zu Hause
- unterwegs
- beim Kunden
- in hybriden Arbeitsmodellen

Dafür braucht man passende Technik:

- Laptop
- VPN oder sichere Verbindung
- Headset
- Webcam
- Cloud-Zugriff
- sichere Anmeldung
- Mehrfaktor-Authentifizierung

---

## Cloud-Anwendungen

Bei Cloud-Anwendungen laufen Programme oder Daten nicht nur lokal auf dem PC, sondern auf Servern in Rechenzentren.

Beispiele:

- Microsoft 365
- Google Workspace
- Cloud-Speicher
- Webanwendungen
- Ticketsysteme
- Kollaborationstools

Vorteile:

- Zugriff von verschiedenen Orten
- zentrale Verwaltung
- einfachere Zusammenarbeit
- oft weniger lokale Installation nötig

Nachteile oder Risiken:

- Abhängigkeit vom Internet
- Datenschutz beachten
- Zugriffsschutz wichtig
- Anbieterabhängigkeit

---

## Virtualisierung

Virtualisierung bedeutet, dass mehrere virtuelle Systeme auf einer physischen Hardware laufen können.

Beispiele:

- virtuelle Maschinen
- Testumgebungen
- Schulungssysteme
- Servervirtualisierung
- später Proxmox oder VMware

Für FISI ist Virtualisierung sehr wichtig, weil man damit Systeme testen, trennen und effizienter nutzen kann.

---

## Green IT

Green IT bedeutet, IT möglichst ressourcenschonend zu nutzen.

Beispiele:

- energieeffiziente Geräte
- längere Nutzungsdauer von Hardware
- sinnvolle Beschaffung
- weniger Stromverbrauch
- Recycling
- Geräte ausschalten oder Energiesparmodus nutzen

Green IT ist wichtig, weil IT viel Strom und Ressourcen verbrauchen kann.

## Praxisbeispiel: Büroarbeitsplatz

Ein Unternehmen braucht neue Arbeitsplätze für normale Büroarbeit.

Mögliche Ausstattung:

- Business-Laptop
- Dockingstation
- zwei Monitore
- Tastatur und Maus
- Headset
- Windows oder Linux
- Office-Programme
- Browser
- E-Mail-Zugang
- Netzwerkzugang
- Druckerzugriff
- Sicherheitssoftware

Für Büroarbeit sind Stabilität, gute Bedienbarkeit und Support oft wichtiger als maximale Leistung.

---

## Praxisbeispiel: Entwicklungsarbeitsplatz

Ein Entwickler braucht meistens mehr Leistung als ein normaler Bürobenutzer.

Mögliche Anforderungen:

- schnelle CPU
- viel RAM
- große SSD
- mehrere Monitore
- Git
- Entwicklungsumgebung
- Terminal
- eventuell virtuelle Maschinen
- Docker oder Container
- Zugriff auf Repositories

Hier ist wichtig, dass der Computer mehrere Tools gleichzeitig flüssig ausführen kann.

---

## Praxisbeispiel: Schulungs- oder Laborarbeitsplatz

Für Schulungen oder Labore sind andere Dinge wichtig:

- einfache Wiederherstellung
- klare Standardkonfiguration
- Netzwerkanbindung
- eventuell virtuelle Maschinen
- Testbenutzer
- Dokumentation
- keine sensiblen Daten

Solche Systeme müssen oft schnell neu installiert oder zurückgesetzt werden können.

## Typische Fehler bei IT-Arbeitsplätzen

Häufige Probleme:

| Problem                          | Mögliche Ursache                                        |
| -------------------------------- | ------------------------------------------------------- |
| PC ist langsam                   | zu wenig RAM, alte HDD, zu viele Programme              |
| Kein Internet                    | Netzwerkproblem, falsche IP, DNS-Problem                |
| Drucker funktioniert nicht       | Treiber fehlt, falscher Drucker, Netzwerkproblem        |
| Benutzer kann Datei nicht öffnen | fehlende Rechte oder falscher Pfad                      |
| Programm startet nicht           | Installation beschädigt oder Abhängigkeit fehlt         |
| Monitor bleibt schwarz           | Kabel, Eingang, Grafikkarte oder Stromversorgung prüfen |

## Kurze Zusammenfassung

Ein IT-Arbeitsplatz besteht aus vielen Teilen: Hardware, Software, Netzwerk, Benutzerkonto, Sicherheit und Peripherie.

Ein Computer arbeitet grundsätzlich nach dem Prinzip Eingabe, Verarbeitung, Speicherung und Ausgabe.

Für FISI ist wichtig, nicht nur einzelne Geräte zu kennen, sondern den kompletten Arbeitsplatz zu verstehen.

Ein guter IT-Arbeitsplatz passt zur Aufgabe des Benutzers, ist sicher, gut dokumentiert und kann später gewartet werden.
